GitHubアップロード用フォルダ

このフォルダの中身をGitHubにアップロードしてください。

【アップロードするファイル一覧】
- app.py
- config.py
- generate_announcement.py
- parse_calendar.py
- requirements.txt
- templates/templates.csv

【アップロード手順】
1. GitHubで新しいリポジトリを作成
2. このフォルダ内のファイルをすべてアップロード
   ※templatesフォルダは「Add file」→「Create new file」で
     「templates/templates.csv」と入力して作成
3. share.streamlit.io でデプロイ
   - Main file path: app.py
